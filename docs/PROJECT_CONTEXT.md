# 项目上下文

## 项目目的

Market Cycle Strategy v0.1 是个人使用的市场阶段、独立仓位区间与期权策略查询原型。它帮助用户按固定场景整理策略，不读取真实账户、不判断当前市场、不执行交易。

## 用户使用流程

1. 在首页查看横向九阶段市场周期图和六张模拟指标卡片。
2. 人工选择一个市场阶段，进入统一模板的阶段详情。
3. 查看 QQQ、SOXX、SOXL、现金/SGOV 的独立允许区间、策略分级、执行动作与风险。
4. 使用阶段对比、期权工具和指标说明页面交叉核对。

## 已确认需求

- 固定九种市场阶段，不合并、不新增。
- 固定八种期权策略，不擅自加入复杂策略。
- 六个指标各自独立切换七个时间范围；v0.1 仅使用模拟数据。
- 各资产仓位区间相互独立，不要求合计为 100%。
- 使用 Hash Router、深浅主题和响应式布局，支持鼠标、触摸和键盘。
- 服务默认监听 `0.0.0.0:48101`，供局域网和 ZeroTier 网络访问。

## 明确排除项

v0.1 不包含真实行情、自动阶段判断、模拟输入规则引擎、确认状态保存、登录、多用户、数据库、IBKR、持仓读取、自动下单、自动回测、推送或后台编辑系统。

## 关键术语

- 市场阶段：用户人工选择的九种预定义市场形态之一。
- 独立仓位区间：单个资产在某阶段的允许范围，不与其他资产区间机械加总。
- 策略分级：阶段详情内对期权工具的推荐、谨慎或不建议标签，不是系统自动建议。
- 模拟指标：用于演示交互和信息结构的静态数值与确定性生成曲线，不是真实行情。

## 后续版本方向

首先完成内容校准与字段完整度；只有用户重新明确范围后，才评估规则引擎、真实数据或只读券商接入。任何真实数据阶段都需要独立设计数据源许可、缓存、更新时间、失败降级和资源上限。
