# 产品与架构决定

## 2026-07-13：保持原生技术栈

- 决定：继续使用原生 HTML/CSS/JavaScript 和 Node.js 原生 HTTP 服务。
- 原因：v0.1 数据固定、交互规模小，无需框架和构建器。
- 影响：部署与维护简单，无第三方运行依赖；复杂状态增长时需重新评估组织方式。
- 重新评估：只有多页面状态、持久化或测试复杂度明显超出现有结构时。

## 2026-07-13：使用 Hash Router

- 决定：路由保持 `#/...`。
- 原因：静态服务器无需重写规则，局域网和 ZeroTier 部署更稳妥。
- 影响：服务器只负责真实静态路径；未知 Hash 由前端显示 404。
- 重新评估：迁移到具备可靠重写能力的正式托管环境时。

## 2026-07-13：冻结九阶段与八期权

- 决定：固定九种市场阶段和八类期权策略。
- 原因：这是用户确认的第一版业务边界。
- 影响：数据检查会阻止无意删除、重复或新增固定枚举。
- 重新评估：仅在用户明确修改产品范围后。

## 2026-07-13：仓位区间相互独立

- 决定：QQQ、SOXX、SOXL、现金/SGOV 的区间不强制加总为 100%。
- 原因：区间表达各资产在场景中的独立允许边界，而非一组同时取值的组合权重。
- 影响：页面和校验不得机械检查上下限总和。
- 重新评估：若未来新增真实组合构建或目标权重计算。

## 2026-07-13：v0.1 不做自动判断和真实数据

- 决定：只展示模拟指标，由用户人工选择阶段；不保存确认状态。
- 原因：避免在数据源、规则和责任边界未确认前制造伪精确结论。
- 影响：没有外部 API、数据库、缓存和定时任务。
- 重新评估：完成内容校准且用户批准独立的数据与规则设计后。

## 2026-07-13：监听 `0.0.0.0:48101`

- 决定：服务默认绑定所有本机网络接口的 48101 端口。
- 原因：需要从局域网和 ZeroTier 虚拟网卡访问。
- 影响：访问安全依赖受控网络和 Windows 防火墙；不配置公网穿透。
- 重新评估：部署环境、网络边界或认证要求变化时。

## 2026-07-13：缺失静态资源返回 404

- 决定：服务器不对缺失文件回退 `index.html`。
- 原因：Hash Router 不需要服务端回退；返回首页会掩盖资源路径错误并产生错误 MIME。
- 影响：真实静态文件错误可被监控和测试发现，未知 Hash 仍由前端处理。
- 重新评估：若未来从 Hash Router 迁移到 History API 路由。
