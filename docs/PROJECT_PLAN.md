# 市场周期策略网站项目计划

## 1. 项目目标

建立一个个人使用的市场阶段与策略查询网站。用户先在首页观察固定市场周期图和辅助指标，再点击具体阶段，查看对应的标的选择、独立仓位区间、期权工具、执行动作与风险收益。

## 2. 第一版需求冻结

- 9种阶段：高位震荡、震荡下跌、单边下跌、恐慌暴跌、底部震荡、右侧反转、单边上涨、震荡上涨、加速上涨/过热。
- 首页采用横向周期图，不采用圆形图。
- 6张指标卡片：PE、前瞻PE、VIX、VXN、恐慌贪婪指数、基金经理仓位指数。
- 每张指标独立切换1个月、3个月、6个月、1年、3年、5年、10年。
- 详情页显示QQQ、SOXX、SOXL、现金/SGOV独立允许区间。
- 8种期权工具：Protective Put、Collar、Put Debit Spread、Put Credit Spread、Covered Call、Cash-Secured Put、Call Debit Spread、Long Call。
- 深色与浅色主题。
- 响应式适配Windows、iPad、iPhone。
- 监听0.0.0.0:48101，支持192.168.31.153与ZeroTier地址访问。

## 3. 第一版排除项

- 实时行情与外部数据源；
- 网页自动判断市场阶段；
- 模拟输入与规则引擎；
- 保存人工确认和每日策略记录；
- IBKR连接；
- 用户登录与多用户；
- 自动下单与回测。

## 4. 当前技术架构

- 前端：原生HTML、CSS、JavaScript；
- 图形：内联SVG；
- 数据：JSON配置；
- 路由：Hash Router；
- 服务端：Node.js原生HTTP静态服务器；
- 持久化：无。

## 5. 开发阶段

### 阶段A：UI原型（当前版本）

- 首页、周期图、指标卡片；
- 9个详情页模板；
- 阶段对比页；
- 期权工具页；
- 指标说明页；
- 深浅主题与响应式布局。

### 阶段B：内容校准

- 逐阶段校准识别条件；
- 校准QQQ、SOXX、SOXL、现金区间；
- 校准每种期权策略在各阶段的推荐等级；
- 补充具体DTE、Delta、行权价选择和退出规则。

### 阶段C：模拟与规则引擎

- 增加趋势、估值、波动、情绪、仓位模拟输入；
- 建立可解释评分规则；
- 仅显示一个系统建议阶段；
- 人工阶段作为最终执行策略。

### 阶段D：真实数据

- 选择并验证PE、前瞻PE、VIX、VXN、情绪和机构仓位数据源；
- 建立缓存、缺失值、更新时间和历史数据处理；
- 明确收盘后更新与盘中更新边界。

### 阶段E：记录与IBKR

- 保存每日系统建议、人工确认和策略快照；
- 接入IBKR只读账户数据；
- 计算实际仓位、Delta敞口、现金比例和账户回撤；
- 自动交易保持独立审批，不与只读版本混合。

## 6. 第一版验收标准

- `http://192.168.31.153:48101`和ZeroTier地址均可打开；
- 9个市场区域均可点击并进入对应详情；
- 6张指标卡片各自独立切换7个时间范围；
- 8种期权策略均显示结构、目的、最大收益、最大亏损、盈亏平衡和风险；
- 深浅主题可切换；
- Windows、iPad、iPhone均能正常使用；
- 市场周期图在窄屏内允许局部横向滚动，不造成整个页面横向溢出；
- JavaScript和服务器语法检查通过；
- `/api/health`返回`ok: true`。
