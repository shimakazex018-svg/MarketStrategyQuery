# 市场数据个人内部使用边界

## 适用范围

本项目中的市场数据仅用于用户本人的投资研究和策略整理。本文件约束所有当前及未来的数据来源、抓取器、缓存、内部 API 和页面展示，不构成对任何数据许可的法律解释。

## 固定用途边界

- 仅用户本人使用，非盈利。
- 网站不向公网开放，不允许公开注册。
- 只允许通过本机、家庭局域网和用户本人的私人 ZeroTier 网络访问。
- 不向第三方提供网站账号、数据源账号或访问凭据。
- 不提供公开市场数据 API，不提供市场数据下载。
- 不销售、授权、转发、发布或再分发市场数据。
- 数据只用于用户本人的投资研究，不用于代客、顾问、商业展示或数据产品。
- 每个指标原则上每天最多更新一次；来源频率更低时按来源实际频率检查。
- 页面必须显示数据来源、数据日期和数据状态；不得把演示、延迟或不可用数据描述为实时数据。
- 未同时通过技术、定义、许可、缓存和内部展示门槛的数据不得进入正式数据路径。

## 数据与仓库边界

- `runtime-data/` 保存运行时缓存、请求状态和日志，整体排除在 Git 之外。
- `.env`、密钥、Cookie、Token、会话、日志、PID 和临时文件不得提交。
- 运行时响应、真实历史序列和每日缓存不得复制到 `public/data/`、测试 fixture、截图清单或文档示例。
- 测试 fixture 只能使用人工构造的最小数据，不得包含从真实账户或受限来源复制的响应。
- 若未来加入IBKR探测脚本，探测输出只能写入 `runtime-data/data-source-probes/ibkr/` 或操作系统临时目录。

当前 `.gitignore` 已覆盖 `runtime-data/`、`.env`、`.env.*`、`*.log`、`*.pid`、`*.tmp` 和常见临时目录；`.env.example` 仅保留空值配置说明。

## 访问与安全边界

- 默认服务监听 `0.0.0.0:48101`，只能在可信家庭网络或私人 ZeroTier 中使用。
- 不配置公网端口映射、反向代理公开入口或第三方共享隧道。
- 当前没有登录鉴权，因此任何超出本人受控网络的访问都不符合本边界。
- 不在浏览器前端保存数据供应商凭据；浏览器只访问本站内部 API。

## Provider启用门槛

Provider只有在以下条件全部成立时才能启用：

1. `complianceStatus` 为 `approved`；或为 `approved_with_conditions` 且全部附加条件已明确满足。
2. `enabled` 明确为 `true`。
3. 指标准确定义、对象、数据日期、机器来源、稳定性和历史覆盖满足产品要求。
4. 许可明确允许本项目的自动读取、本人内部网页展示、本地缓存和所需历史保存。
5. 所需账户、订阅、协议和归属标注已完成，并有可审计证据。
6. 当前 Windows 主机已完成不含敏感信息的技术验证。

技术返回成功、端点公开、无需API Key或已经支付订阅，均不能单独代表许可通过。
