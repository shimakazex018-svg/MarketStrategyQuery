# 测试与验收

## 自动检查

要求 Node.js 18 或更高版本：

```powershell
npm.cmd run check
```

该命令执行服务器和前端语法检查，并校验 9 个阶段、8 个期权、6 个指标、7 个时间范围、阶段顺序、相邻阶段、四资产规则、八策略分级、情景动作、期权管理字段、公式变量、指标说明字段、周期图点位和全部引用。

## 启动

```powershell
npm start
```

也可运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-market-site.ps1
```

启动前检查 48101 端口；若被占用，先识别 PID，不终止未知进程。

## API 与 HTTP 检查

- `GET /api/health`：应返回 HTTP 200 与 `{"ok":true,"version":"0.1.0"}`。
- `/`、`/styles.css`、`/app.js` 和三个 JSON：应返回 200 及正确 MIME。
- 缺失静态文件：应返回 404 `text/plain`，不得回退首页。
- 编码错误或越界路径：不得暴露 `public/` 之外的文件。

## 页面回归清单

- 首页加载九阶段周期图和六张指标卡。
- 任一上涨阶段和任一下跌阶段各显示四类仓位。
- 高位震荡、恐慌暴跌和右侧反转应显示状态定义、四资产仓位、默认初始动作和风险边界；相邻阶段区别不再渲染。
- 阶段动作和资产标签同一时间各只显示一个面板，左右方向键可切换并同步 `aria-selected`。
- 识别图字段缺失时不出现空白图片；存在合法图片数据时应显示标题、替代文本、说明、来源和周期。
- 阶段对比显示九行。
- 期权工具目录保留八种策略，同一时间只完整显示一张详情。
- `#/options/:id` 切换、刷新、前进和后退均恢复正确策略；阶段页策略链接直达对应详情。
- 单策略始终显示买卖腿、最大收益、最大亏损、盈亏平衡与主要风险；详细分组可用 Enter 和 Space 展开。
- 变量说明与公式示例折叠可使用 Enter 和 Space 打开/关闭，并同步 `aria-expanded`。
- 指标说明显示六行。
- 未知 Hash 显示前端 404。
- 深色和浅色主题均可切换。
- 单个指标切换周期时，其他指标保持原周期。
- SVG 阶段区域可用 Enter/Space 打开详情。
- 周期图读取 `cycle-shape.json`，阶段聚焦或触摸时更新摘要；窄屏只在图表容器内横向滚动。
- 指标信息按钮打开模态说明；Escape、遮罩和关闭按钮可关闭，焦点返回原按钮。
- 移动菜单可打开、关闭、按 Escape 收起，并同步 `aria-expanded`。

## 响应式视口

至少检查 `375×812`、`768×1024`、`1024×1366`、`1440×900`：

- 页面级 `scrollWidth` 不得大于 `clientWidth`。
- 周期图只在自身容器内横向滚动。
- 375px 显示移动菜单；其余目标宽度按设计显示桌面导航。
- 指标网格在手机为一列、平板为两列、桌面为三列。
- 表格可在容器内横向滚动。
- 控件焦点、触摸区域、对比度和减少动画设置可用。
- 长文本不得溢出卡片或被固定高度裁切。

## 人工设备验收

- Windows：Chrome/Edge 检查缩放 100% 与 125%、键盘 Tab 顺序、主题和所有路由。
- iPad：横竖屏检查周期图与表格的局部横向滚动，不触发整页溢出。
- iPhone：检查安全区域、菜单、按钮触摸、长中文换行和滚动性能。
- 深浅主题均检查文字、标签、按钮和图表对比度；红绿状态必须同时有文字标签。

## ZeroTier 验收

1. 服务器保持 `0.0.0.0:48101` 监听。
2. 防火墙仅允许本项目 TCP 48101 的 Private 入站规则。
3. 同一 ZeroTier 网络中的另一设备请求 `http://<ZeroTier-IP>:48101/api/health`。
4. 再打开首页和一个阶段详情，确认静态资源完整加载。

## 当前无法完全自动化的项目

真实 iPad/iPhone 触摸体验、系统字体差异、局域网/ZeroTier 路由和 Windows 防火墙策略需要目标设备人工验证。
