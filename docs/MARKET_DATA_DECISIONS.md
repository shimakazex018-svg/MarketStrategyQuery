# 市场数据决策记录

## MD-015：本地 OHLCV 优先于新增网络 Provider

- 状态：已接受
- 日期：2026-08-10
- 决策：目标资产的第一版统一输入层只支持用户本地 CSV，支持 QQQ、SOXX、SOXL、TQQQ、SPY；不在本轮启用 IBKR、Twelve Data、Alpha Vantage 或其他新网络 Provider。
- 结果：真实文件、标准化结果和派生结果继续留在被忽略的 `runtime-data/`；页面只访问本站内部 API。

## MD-016：派生指标不伪造缺失连续性

- 状态：已接受
- 日期：2026-08-10
- 决策：校验日期顺序、重复、非有限值、OHLCV 边界、成交量和日历空洞；空洞保留为质量警告，不插值，不用 0 或演示值补齐。
- 结果：每个派生模型携带来源、数据日期、质量状态、限制和公式版本。

## MD-001：许可门槛优先于端点可访问性

- 状态：已接受
- 日期：2026-07-14
- 决策：只有“机器可读且允许本项目自动读取、缓存和再展示”的来源才能默认启用。HTTP 200 或无需 Key 不等于获得数据许可。
- 结果：Cboe VIX/VXN CSV 的技术适配器可以实现和测试，但在取得书面许可前默认禁用。

## MD-002：FRED 不用于绕过 Cboe 权利

- 状态：已接受
- 决策：`VIXCLS` 是 Cboe 版权系列。FRED API 的可访问性不覆盖原数据所有者权利，当前 API 条款还与本项目持久缓存要求冲突，因此不把 FRED 当作规避 Cboe 许可的生产备选。
- 结果：`FRED_API_KEY` 保留为未来可选配置；没有 Key 不影响启动。

## MD-003：QQQ 组合 PE 与指数 PE 严格分离

- 状态：已接受
- 决策：QQQ 组合 TTM PE 与 Nasdaq-100 指数 TTM PE 使用不同 ID、对象和来源说明，禁止互相替代或拼接历史。
- 结果：Invesco 来源未通过门槛时，现有卡片保留演示值并明确标记，不改成“Nasdaq-100 PE”。

## MD-004：不从 PDF/网页 DOM 建立生产抓取

- 状态：已接受
- 决策：公开 PDF 可以作为口径审计证据，但除非存在明确许可、稳定 URL、结构化字段和可验证日期，否则不作为生产抓取源；普通网页、仪表盘、页面内部私有接口和浏览器自动化一律不用于市场数据采集。
- 结果：QQQ PE、Forward PE、CNN Fear & Greed 与 NAAIM Exposure Index 本轮保留演示数据。

## MD-005：无数据库的原子文件缓存

- 状态：已接受
- 决策：v0.3 使用按指标拆分的 JSON 缓存和持久化请求状态，不引入数据库或第三方包；写入采用临时文件加原子替换，日志有界轮转。
- 原因：六个指标的数据量很小，文件缓存更符合当前部署与维护成本；职责仍保持模块化，未来可替换存储实现。

## MD-006：页面访问不触发外部抓取

- 状态：已接受
- 决策：GET 指标 API 只读内存/本地缓存。外部访问仅来自启动过期检查、工作日调度或受限手动维护接口。
- 结果：多浏览器并发不会放大第三方流量，断网也不阻塞页面启动。

## MD-007：状态比伪造连续性更重要

- 状态：已接受
- 决策：无缓存失败返回 `error`，许可未通过返回 `unavailable`，静态数据返回 `demo`；不使用 0、不用模拟点补齐真实历史、不混合多个来源形成未标记曲线。

## MD-009：Provider登记成为环境变量之前的硬门禁

- 状态：已接受
- 日期：2026-07-15
- 决策：Provider必须先在 `config/market-data-providers.json` 通过合规状态验证；运行时环境变量只能作为第二确认，不能把待确认、拒绝、技术不可用或未评估来源变为已批准。
- 结果：Cboe与IBKR当前均禁用；生产服务不会因设置旧许可变量而访问它们。

## MD-010：IBKR首选Gateway/TWS Socket协议但保持待书面确认

- 状态：已接受
- 日期：2026-07-15
- 决策：若后续获准，先用TWS做可见只读验证，再评估以资源占用更低的IB Gateway运行同一TWS API协议；不优先使用需要持续会话维护的Client Portal Gateway。
- 结果：本机组件缺失、登录和2FA必须由用户完成；VIX/VXN内部显示、缓存、历史保存和精确订阅取得书面确认前不创建正式适配器。

## MD-011：v0.4转向自计算市场指标

- 状态：已接受
- 日期：2026-07-15
- 决策：当前阶段不继续IBKR、Twelve Data或Alpha Vantage路线；保留其评估历史和合规门禁，但使用本地CSV、SEC EDGAR公共财务数据设计与CFTC COT公共持仓数据设计建设自计算指标。
- 结果：IBKR登记为`not_selected_by_owner`，Twelve Data与Alpha Vantage登记为`deferred`；三者均保持`enabled=false`，本阶段不请求数据。

## MD-012：自建指标不得冒充第三方专有指标

- 状态：已接受
- 日期：2026-07-15
- 决策：正式目标卡定义为自计算QQQ组合TTM PE、Forward PE人工录入、QQQ实现波动率、QQQ波动率历史分位、自建风险偏好指数、Nasdaq期货机构仓位代理。
- 结果：不得把自建结果命名为VIX、VXN、CNN Fear & Greed、NAAIM Exposure、Invesco官方PE或Nasdaq官方PE；检查点A不修改正式首页卡片。

## MD-013：覆盖率优先于估值连续性

- 状态：已接受
- 日期：2026-07-15
- 决策：QQQ PE财务覆盖权重低于90%、价格覆盖权重低于95%、币种不一致、日期不明或结果非有限正数时，返回`insufficient_coverage`且正式值为`null`。
- 结果：同时计算包含亏损和排除亏损后重归一化的候选结果，默认版本留待用户审定；不得用旧值冒充fresh。

## MD-014：风险偏好先用透明等权原型

- 状态：已接受
- 日期：2026-07-15
- 决策：检查点A只实现`RISK-APPETITE-v1-EW`等权聚合，不使用机器学习、不根据样本擅自优化权重。
- 结果：缺失分项不填0，至少5/7可用才输出候选分数；最终权重和映射阈值仍待用户审定。

## MD-015：WorldPEratio只建立待许可的低频外部参考原型

- 状态：已接受
- 日期：2026-07-15
- 决策：`MD-004` 对未经逐来源授权的普通网页生产采集仍有效；本次用户明确授权对 WorldPEratio 做单来源审计和默认禁用原型。普通 HTTP 已返回公开 Nasdaq-100/QQQ 目标字段，因此不启用浏览器自动化。
- 结果：该第一检查点结论由 MD-016 对 WorldPEratio 单一来源部分取代；默认禁用原则仍适用于其他公开网页来源。

## MD-016：WorldPEratio按项目所有者有限风险接受边界启用

- 决策：登记为`approved_with_conditions`、`selected`、`conditionsSatisfied=true`、`enabled=true`和`owner_accepted_limited_internal_use`。这不是WorldPEratio书面授权。
- 请求边界：每次采集先检查30天条款复查状态和robots；每天最多一次目标请求，仅超时或5xx延迟重试一次；复查到期、403、429、登录、验证码、Cloudflare、robots禁止或结构冲突立即停止。
- 存储边界：只保存标准化字段、内部内容哈希、请求状态和去重快照，不保存HTML；运行目录由Git忽略。外部参考不得覆盖本站自计算PE。
- 展示边界：只进入PE详情页的“外部参考PE”分区，不改变首页六卡布局。没有完整公开历史序列时只显示汇总统计区间和本站逐日快照，不反推历史曲线。
